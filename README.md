# 美股缠论交易系统

以美股为主、融合**缠论**结构分析与**期权策略**的本地交易系统。自动扫描、自动识别买卖点、每日更新。

## 〇、两个市场：美股 / 港股通

| | 美股 US | 港股 HK |

| 展示 | AAPL | 00700.HK |

## 〇·五、选股思想

> 这一节讲**系统凭什么选出一只票**。功能说明在「二、核心功能」，这一节只讲判断逻辑与取舍理由。

### 1. 一句话概括

**不预测涨跌，只在「位置 + 资金 + 估值」同时给出有利证据时才出手；证据越多，仓位越大。**

系统从不回答"明天涨不涨"，只回答一个更朴素的问题：
**此刻买入，我承担的风险和我可能拿到的回报，配不配得上？**
这个问题被拆成三个可计算的子问题。

### 2. 三个维度，各自只回答一个问题

| 维度 | 回答的问题 | 引擎 | 典型判据 |
|---|---|---|---|
| **位置**（缠论） | 现在处在趋势的哪个**位置**？ | `chanlun.py` | 中枢 / 离开段 / 背驰 / 一二三类买卖点 |
| **资金**（量价） | 这个位置有没有**资金认可**？ | `volprice.py` | 量比 / OBV / MFI / CMF / 五类买卖形态 |
| **估值**（基本面） | 这个价格**贵不贵**，值不值得？ | `fundamental.py` | PE 带分位 / 价格分位 / 52 周位置 |

三条各自独立、互不替代：

- **只有位置对**：形态走好了但没钱进来，多半是无人问津的技术性反抽 —— 不做；
- **只有资金对**：放量涨但处在下跌中枢的离开段里，是反弹不是反转 —— 轻仓或不参与；
- **只有估值对**：便宜不是上涨理由，便宜可以更便宜 —— 估值只调仓位，不做触发器。

### 3. 第一层：位置 —— 用缠论给"位置"一个客观定义

选股最容易犯的错，是把**"跌了很多"**当成**"跌到位了"**。缠论的价值就在于把"位置"变成可判定的结构，而不是感觉。

核心判断单元是**中枢**与**离开段**：

```
中枢 = 多空平衡区（反复重叠、方向未定）
离开段 = 失衡区（一方主导）
背驰 = 离开段创了新极端，但力度（MACD 柱面积）反而衰减
```

由此定下三条出手铁律：

| 铁律 | 说明 |
|---|---|
| **只在中枢外出手** | 中枢内是平衡区，出手等于猜方向；系统不在无方向处下注 |
| **只在离开段力度衰竭时反向** | "下跌离开段创新低 + MACD 柱面积缩小" 才是 B1，单纯新低不是 |
| **只在回调不破关键位时加码** | B2 = 回调不破一买低点；B3 = 回调不跌回中枢上沿 ZG |

对应到卖出，则是 S1 顶背驰 / S2 反抽不破高 / S3 反抽不回中枢下沿 ZD —— **同一套结构语言的正反两面**。

**多级别联立**是这一层的放大器：周线定方向，日线找入场。日线出现买点、周线趋势同为向上时，
信号才真正可靠；反之若周线处于中枢下方且趋势向下，日线的买点要打折看待。

> 信号有时效性过滤（默认 45 个交易日）—— 三个月前的买点已经不是买点了。

### 4. 第二层：资金 —— 用量能验证价格形态

缠论只读价格形态，它不知道"这个形态有没有人认"。量价层补上这一票。

```
价涨量增 = 健康上涨        价涨量缩 = 上涨乏力
价跌量增 = 恐慌抛售        价跌量缩 = 抛压衰竭
```

五种买入证据：`VP_B1` 放量突破、`VP_B2` 缩量回踩、`VP_B3` 地量止跌、
`VP_B4` 底部放量反转、`VP_B5` 量价底背离。
背离判定用**波段枢轴点对比**而非窗口极值——后者在趋势股里几乎天天误报。

**这一层的定位是"确认/过滤"，不是"独立开仓依据"。** 实测的三条诚实结论（15 只标的 / 3 年）：

| 信号源 | 样本外平均单笔 |
|---|---|
| 缠论买卖点 | −0.95% |
| 量价关系 | −0.16% |
| 缠论 + 量价共振 | **+1.44%** |

即：**共振质量最高，但样本极少（15 只标的 3 年仅 69 笔，约 1.5 笔/只/年）**。
所以它适合当"高置信度提醒"，不适合当主要信号源；两者矛盾时，做法是**降低仓位**，而不是二选一。

### 5. 第三层：估值 —— 决定"敢上多少"，不决定"买不买"

位置对、资金对之后，才轮到估值。它的作用只有一个：**调节仓位与工具选择**。

系统并行给出两种口径，互为交叉验证：

| 口径 | 假设 | 用途 |
|---|---|---|
| **价格分位**（1y/3y/5y） | 无假设 | 最朴素：现在的价格在过去 N 年里排在什么位置 |
| **PE 带**（箱线 min/p25/中位/p75/max） | **EPS 不变** | 回答"按今天的赚钱能力，这价格在历史贵不贵" |

PE 带用当前 EPS 反推历史价格，**不是历史真实 PE**（免费源拿不到 PE 序列），
这一点界面上有明确标注 —— 所以它必须和无假设的价格分位一起看。

用法对照：

| 评级（分位） | 仓位取向 | 工具取向 |
|---|---|---|
| < 20 明显便宜 | 敢上标准仓位 | 敢用 LEAPS 长期看涨（时间站在你这边） |
| 20–40 低于中枢 | 正常偏积极 | 买 Call / 牛市价差 |
| 40–60 中枢附近 | 标准仓位 | 价差为主 |
| 60–80 高于中枢 | 减半仓位 | 价差封顶，不做裸买 |
| > 80 明显偏贵 | 只看不做，或极小仓位 | 卖方 / 保护性 Put |

**估值永远不产生买卖信号。** 它只改变"这次下多大的注、用什么工具"。

### 6. 四套策略：同一套思想在四种市场环境下的具体形态

| 策略 | 在赚什么钱 | 前提（必要条件） | 主要风险 | 系统怎么防 |
|---|---|---|---|---|
| **超跌反弹** | 跌透后的均值回归 | 52 周深度回撤（12% 起计分，≥30% 才算充分）+ RSI 超卖 + 跌势衰竭 | 接飞刀，跌了还能再跌 | 必须见到背驰或 B1；「放量下跌且未见背驰」**扣 10 分** |
| **趋势突破** | 趋势延续 | 站上 20/55 日唐奇安上轨 + 量比 ≥1.2 + 均线多头（MA20>MA60） | 假突破 | 量能独立计分最高 25 分；出现 S1 **扣 25 分**、S3 扣 15 分 |
| **底部反转** | 拐点 | 缠论买点 + K 线确认 + MACD 转向 | 反转未确认 | 同时存在卖点 **扣 20 分** |
| **量价共振** | 资金先于价格动 | 量能形态成立 | 样本少、易伪 | 只取买入形态，卖出形态走独立提醒通道 |

四套策略的**共同设计原则**：

1. **多条件叠加，不是单一指标触发。** 每个策略由 5–9 个加分项累加而成，满分 100。
2. **必须有明确的扣分项。** 反向信号、加速下跌、量价背离都是负分 —— 系统宁可漏，不愿错。
3. **有证据门槛。** 低于阈值（超跌 55 / 突破 60 / 反转 55 / 量价 58）直接不进结果，不给你"勉强算命中"的东西。
4. **每条命中可解释。** 逐条列出命中原因与具体数值，不是黑箱打分。

### 7. 分数的正确用法（和常见误用）

| ✅ 正确 | ❌ 错误 |
|---|---|
| 分数 = **证据充分度**，用于当天**排序** | 把 80 分理解成"80% 概率会涨" |
| 同分时看**扣分项**（有没有卖点警告） | 只看分数，忽略界面里的红色警告 |
| 跨策略横向比较**阈值**而非绝对值 | 拿超跌的 70 分和突破的 70 分当同一件事 |
| 仓位由**估值和止损空间**决定 | 分数高就重仓 |

> 分数是条件满足度的加权和，**不是概率，也不是预期收益**。它回答的是"证据齐不齐"，不回答"能赚多少"。

### 8. 从候选到下单的完整链路

```
① 选池子        自选股票池 / 全市场扫描 / 热点板块（资金最集中的地方）
                     ↓
② 并行打分      四套策略同时对每只票打分 → 过阈值 → 按分数降序
                     ↓
③ 看结构        点开个股：日线找买点，切周线确认大级别方向（多级别联立）
                     ↓
④ 资金确认      量价是否共振？有没有反向的卖出警告？
                     ↓
⑤ 定仓位        基本面分位决定上多少；止损空间按 ATR/固定幅度算
                     ↓
⑥ 选工具        期权矩阵：期限（短 30-45 天 / 长 240 天）× 方向（Call/Put）
                 IV 偏高→卖方策略，IV 偏低→买方策略
                     ↓
⑦ 下单前两问    止损在哪？这笔亏了我认不认？
                     ↓
⑧ 复盘闭环      5/10/20 日胜率 + MFE/MAE → 参数自迭代 → 回到 ①
```

第 ⑧ 步不是装饰。系统内置了**信号复盘**（按 B1/B2/B3/S1/S2/S3 分别统计胜率）、
**无未来函数回测**、以及**样本内/样本外自迭代**——它是在用历史数据持续检验上面这套思想还成不成立。

### 9. 刻意不做的事（系统的边界）

| 不做 | 原因 |
|---|---|
| 不预测目标价、不预测财报 | 只做"当下证据是否充分"，预测不在能力圈内 |
| 不做左侧重仓 | 超跌也要求背驰确认，右侧才动 |
| 不把单一指标当信号 | 所有命中都是多条件叠加 + 扣分项 |
| 不用样本内成绩说话 | 所有结论一律看样本外（见二·五、二·六） |
| 不做日内/高频 | 数据是延迟日线，决策粒度就是日线 |
| 不用估值择时 | 估值只调仓位与工具，择时交给结构与资金 |
| 不在无方向的震荡区出手 | 中枢内不出手 |

### 10. 已知弱点（诚实清单）

- **三个信号源样本外都在退化**（缠论 −0.95% / 量价 −0.16% / 共振 +1.44%），
  说明当前的**出场参数**是在样本内调出来的，已不适应近 9 个月的市场 —— 下一步该解决的是出场，不是继续加信号。
- **共振信号样本太少**（约 1.5 笔/只/年），统计意义有限。
- **参数会随市场环境漂移**，建议每月用更大的标的池重跑一次自迭代。
- **港股缺总市值、股息率、历史 PE**（免费源无），估值页以「—」显示，不编造。
- **「资金流」是 Chaikin A/D 估算值**，不是交易所真实资金流；
  它衡量的是"收盘在当日区间的位置"，所以会出现"股价涨但资金净流出"，这是模型定义，不是 bug。
- **缠论本身有主观性**，不同参数（成笔 K 线数、背驰阈值）会得出不同结构，建议交叉验证。

## 二、核心功能

### 1. 缠论引擎（实用简化版）

完整链路：`K线包含处理 → 分型 → 笔 → 线段 → 中枢 → 背驰 → 一/二/三类买卖点`

| 模块 | 实现要点 |
|---|---|
| 包含处理 | 按方向合并（向上取高高/低高，向下取低低/高低） |
| 分型 | 顶分型：中间K线高低点均为三者最高；底分型反之 |
| 笔 | 顶底分型交替，间隔 ≥ 4 根合并K线（经典 5 根成笔） |
| 中枢 | 连续 3 笔及以上重叠区间，ZG=上沿、ZD=下沿，支持中枢延伸 |
| 背驰 | MACD 柱同色面积比较，后段价格更极端但力度衰减即为背驰 |
| 买卖点 | 一/二/三类买点与卖点（定义见下） |

**买卖点定义：**

| 信号 | 含义 | 触发条件 |
|---|---|---|
| **B1 一类买点** | 趋势底背驰 | 下跌中枢后，向下离开段创新低但 MACD 柱面积缩小 |
| **B2 二类买点** | 回调确认 | 一买后反弹，回调不破一买低点 |
| **B3 三类买点** | 中枢上方企稳 | 向上离开中枢后回调，低点不跌回中枢上沿 ZG |
| **S1 一类卖点** | 趋势顶背驰 | 上涨中枢后，向上离开段创新高但力度衰竭 |
| **S2 二类卖点** | 反抽确认 | 一卖后回落，反抽不破一卖高点 |
| **S3 三类卖点** | 中枢下方受阻 | 向下离开中枢后反抽，高点不升回中枢下沿 ZD |

每个信号附带**信号价、止损参考、置信度与文字理由**。

**多级别联立**：详情页可在 **日线 / 周线** 间切换。缠论讲「区间套」——大级别定方向、小级别找入场。
例如 TSLA 日线出现 S3 卖点，切到周线可见趋势同为 down、且处于周线中枢下方，卖点可靠性更高。

> 信号有时效性过滤（默认 45 个交易日内），数月前的陈旧点位不会展示。

### 2. 四种自动选股策略

| 策略 | 逻辑 | 典型触发 |
|---|---|---|
| **超跌反弹** | 深度回撤 + 超卖 + 底背驰 | 距 52 周高点回撤 >20%、RSI<30、触及布林下轨、缠论 B1 |
| **趋势突破** | 放量突破 + 均线多头 | 突破 20/55 日唐奇安上轨、量比 >1.5、MA20>MA60、缠论 B3 |
| **底部反转** | 分型 + 背离 + K线形态 | 缠论 B1/B2、MACD 柱翻红、RSI 脱离超卖、锤子线/看涨吞没 |
| **量价共振** | 量能验证价格 | 放量突破 / 缩量回踩 / 地量止跌 / 底部放量 / 量价底背离（详见二·六） |

每条命中给出 **0-100 评分** 与逐条命中原因（可解释，非黑箱）。
量价策略只把**买入**形态计入选股排名；卖出形态走独立的「量价提醒」通道。

> 评分代表**证据充分度**（用于排序），不是上涨概率；四套策略背后的取舍逻辑、
> 以及「位置 / 资金 / 估值」三层如何配合，见 **〇·五、选股思想**。

### 3. 每日自动更新

内置定时任务（APScheduler），默认**每天 05:30**（北京时间，美股收盘后）自动扫描股票池并入库。时间可在「系统设置」中调整。

### 4. 正股 + 期权

缠论信号 → 期权策略自动映射：

| 场景 | 推荐策略 |
|---|---|
| B1/B2（超跌、反转） | **现金担保卖出看跌 CSP**（在支撑位接货）或 买入看涨 |
| B3 / 突破 | **买入看涨** 或（IV 偏高时）**牛市看涨价差** |
| S1/S2/S3 且持股 | **备兑看涨 Covered Call** |
| S1/S2/S3 且空仓 | **买入看跌** 或 熊市看跌价差 |
| 无信号 + 持股 | 卖出虚值 Call 增厚收益 |

期权合约按 **Delta / Moneyness** 自动筛选，并计算 Greeks（Black-Scholes）。
用 **IV/HV 比值**判断期权贵贱：偏贵时优先卖方策略，偏便宜时优先买方策略。

> **数据说明**：系统优先使用实时期权链；若无法获取，会自动降级为基于历史波动率的
> Black-Scholes **理论估算报价**（界面会明确标注）。实盘请以券商报价为准。

### 4.5 期权策略矩阵（期限 × 方向）

同一笔缠论信号，在**短期**和**中长期**下该做的操作完全不同——期权的取舍本质只有一个：**时间**。

| 期限 | 目标 DTE | 特点 | 适合 |
|---|---|---|---|
| 短期 | 约 30–45 天 | Theta 衰减最快、Gamma 大、杠杆高 | 买卖点刚确认、趋势即将启动或破位 |
| 中长期（LEAPS） | 约 6–12 个月（240 天） | Theta 衰减慢、容错时间长 | 周线级别方向明确、长期持有、给持仓上保险 |

每个期限再按 **CALL / PUT** 分开，两侧各给出 3 套策略，每套都带 **操作建议**（具体怎么做）
和 **操作理由**（为什么这么做）：

**短期 · CALL**
| 策略 | 角色 | 建议要点 | 理由 |
|---|---|---|---|
| 买入看涨期权 | 买方 | 买 Delta 0.55–0.65 的近月 Call，单笔 2–5% 仓位 | 杠杆最高、亏损锁定；代价是 Theta 快，信号证伪必须立刻走 |
| 牛市看涨价差 | 价差 | 买低行权价 Call + 卖高行权价 Call | 卖腿收租降低净成本与 Theta 损耗，代价是收益封顶 |
| 备兑看涨 | 卖方 | 每 100 股卖 1 张 Delta 0.25–0.3 虚值 Call | 把"横盘不涨"也变成收益；代价是上涨封顶 |

**短期 · PUT**
| 策略 | 角色 | 建议要点 | 理由 |
|---|---|---|---|
| 买入看跌期权 | 买方 | 买 Delta ≈ -0.5 的 Put，按每 100 股配 1 张 | 有限权利金博下跌，比融券安全；作为保险可锁定最坏情况 |
| 熊市看跌价差 | 价差 | 买高行权价 Put + 卖低行权价 Put | 净成本更低，适合"看空但幅度有限" |
| 现金担保卖出看跌 | 卖方 | 在缠论一/二类买点卖 Put，预留全额现金 | 涨/横盘白赚权利金，跌了按更低成本接货 |

**中长期 · CALL**
| 策略 | 角色 | 建议要点 | 理由 |
|---|---|---|---|
| 长期看涨期权（股票替代） | 买方 | 买 Delta 0.7–0.85 的深度实值 Call | 涨跌几乎同步跟随正股，资金占用只有直接持股的 30–50% |
| 长期看涨 + 卖近月 Call（PMCC） | 组合 | 买 LEAPS + 逐月卖虚值近月 Call | 用长期仓位替代持股，再持续卖近月收租降低成本 |
| 长期备兑看涨 | 卖方 | 每 100 股卖出 1 张远月虚值 Call | 长期持有者增厚收益，行权概率低 |

**中长期 · PUT**
| 策略 | 角色 | 建议要点 | 理由 |
|---|---|---|---|
| 长期卖出看跌 | 卖方 | 卖 240 天虚值 Put，预留现金 | 长周期反复收租；被行权即为长期建仓 |
| 保护性看跌 | 买方 | 每 100 股买 1 张远月 OTM Put | 给持仓设"地板"，上涨空间全部保留 |
| 领口策略 | 组合 | 持股 + 买 Put + 卖 Call（净成本极低） | 用卖出 Call 的权利金补贴保险成本，代价是封顶 |

**打分如何随场景变化**：每个策略按「信号方向（看多/看空/中性）+ IV 环境 + 是否持股 + 策略角色」
实时打分排序。例如出现 B2 买点且空仓时，短期首选 **牛市看涨价差**；
出现 S2 卖点且持股时，短期首选 **熊市看跌价差**、中长期首选 **保护性看跌**。

接口：`GET /api/symbol/{symbol}/options` → 返回体新增 `horizons` 字段。

### 4.6 市场热点板块（资金流向）

一页回答三个问题：**钱在哪儿最活跃、往哪儿进、从哪儿撤**。

| 模块 | 内容 |
|---|---|
| ① 活跃 TOP10 板块 | 按「活跃度 = 0.62×成交额分位 + 0.38×量比分位」排序，含成交额、占全池比重、量比、净额 |
| ② 资金流入 TOP5 板块 | 净流入金额降序 |
| ③ 资金流出 TOP5 板块 | 净流出金额升序 |
| ④ 资金流入 TOP10 个股 | 全市场约 170 只主流美股 |
| ⑤ 资金流出 TOP10 个股 | 同上 |
| 行业资金流聚合 | 按个股所属行业汇总，与板块 ETF 榜互为交叉验证 |

**覆盖范围**：38 个板块 ETF（11 大 GICS 行业 XLK/XLF/XLV/XLE/XLI/XLY/XLP/XLB/XLU/XLRE/XLC
\+ 半导体、生物科技、金矿、油气、锂电、稀土、铀矿、机器人、网络安全、云软件、国防、基建等主题）
\+ 约 170 只主流美股（按 GICS 一级行业标注）。

**点击即分析**：五个榜单的每一行都可点击 → 直接进入「个股分析」页跑缠论（笔/中枢/买卖点）。
- 个股行 → 分析该股
- 板块行 → 分析对应板块 ETF（如点「半导体」= 分析 SMH）
- 行业聚合行 → 分析该行业的代表 ETF（如「科技」→ XLK）
- 每行悬停出现 **+池** 按钮，可一键加入股票池（不触发跳转）
- 进入分析页后顶部有 **← 返回热点板块**，可直接跳回

**资金流口径（务必先看这段）**：美股没有免费的交易所级真实资金流。系统用经典的
**Chaikin A/D 累积派发线** 从公开 OHLCV 推算：

```
MFM = ((C - L) - (H - C)) / (H - L)        ∈ [-1, +1]，收盘在当日区间的位置
净流入(N日) = Σ (MFM × Volume × Close)
```

这是**估算值，不是真实资金流**。两条必须知道的模型特性：

1. **A/D 看的是「收盘在当日区间的位置」，不是涨跌。**
   高开低走——即使收涨——也会计为流出。所以会出现「股价涨但资金净流出」（如 MU 涨 1.78% 却净流出）。
   **这不是 bug，是模型定义。**
2. **绝对金额受规模影响巨大。** 大市值板块天然金额大。
   所以额外提供 **强度 = 净流入 / 成交额（%）**，剔除规模后横向可比，建议交叉验证。

页面同时区分 **涨跌家数**（价格口径）与 **资金流家数**（A/D 口径），两者经常背离，
不做区分会误读。

接口：`GET /api/hotspots?window=5&mode=full&market=US`
- `window`：统计窗口（交易日），1/3/5/10/20
- `mode`：`full` 拉日线算 N 日累计（首次 20-30 秒，5 分钟内走缓存）；
  `fast` 只用实时报价算当日（1-2 秒）
- `market`：`US` 美股 38 板块 ETF + 170 股；`HK` 港股 9 个 ETF + 106 只港股通标的。

其他市场相关接口：`GET /api/markets`（市场元信息）、`GET /api/universe?market=HK`（标的池）、
`GET /api/watchlist?market=HK`（按市场过滤股票池）。

**实测对照（同一时刻两个市场）**：

| | 港股 HK | 美股 US |
|---|---|---|
| 覆盖范围 | 9 板块 / 106 股 | 38 板块 / 173 股 |
| 市场情绪 | 资金整体进场 | 资金整体撤离 |
| 活跃第一 | 盈富基金（恒指）510 亿港元 | SMH 半导体 188 亿美元 |
| 流入第一 | 阿里巴巴-W +62.7 亿 | AMD +181.0 亿 |
| 流出第一 | 腾讯控股 -159.8 亿 | 英伟达 -872.2 亿 |

### 5. 持仓盈亏

在股票池填写股数与成本价后，「持仓盈亏」页实时计算市值、盈亏额、盈亏%，
并结合当前缠论信号给出操作建议。例如持仓亏损且出现卖点时，会提示
「考虑减仓或备兑看涨」——把信号直接落到你手上的仓位。

### 6. 信号复盘（胜率追踪）

一个只报信号、从不回看的系统无法验证自己。复盘模块会回溯每个信号之后
**5 / 10 / 20 个交易日**的表现：

- **胜率**：买点看涨、卖点看跌，判断正确即为胜
- **平均收益**：该窗口内的平均涨跌幅
- **MFE / MAE**：区间内最大有利偏移 / 最大不利偏移，用于评估盈亏比

可按信号类型（B1/B2/B3/S1/S2/S3）分别统计，据此调整参数。
样本量小于 30 时界面会明确提示统计意义有限。

### 7. 策略回测

在历史数据上完整回放：信号 → 次日开盘入场 → 止损/止盈/超时/反向信号出场，
输出胜率、盈亏比、最大回撤、夏普、权益曲线与逐笔明细。

**严格避免未来函数**：回测位置 i 只能使用 `end_raw + confirm_delay <= i` 的笔与中枢，
也就是"当时已确认"的结构；信号次日开盘成交，跳空按不利价格成交。
回测与实盘共用 `ChanEngine.find_signals` 同一套判定逻辑，保证结果可比。

### 8. 参数自迭代（自学习）

这是让系统自我进化的闭环：

```
随机采样参数组合 → 样本内(前70%)择优 → 样本外(后30%)验证 → 达标才允许应用
```

防过拟合的三道防线：
- **样本内/样本外时间分割**——样本外才是真实检验
- **最少交易数门槛**——样本太少的参数组直接淘汰
- **拒绝机制**——样本外未超越默认参数时，系统拒绝应用并提示保持默认

可搜索的参数：成笔K线数、背驰阈值、止损%、止盈%、最大持有、
是否用缠论关键位止损、是否反向信号出场。目标函数可选收益/回撤比、
平均单笔收益、夏普、盈亏比、胜率。

> 本次已用 20 只标的 / 3 年数据完成一轮迭代并应用，结果见下节。

## 二·五、本轮自迭代结果（20 只标的 / 3 年 / 40 组采样）

| | 样本内(前70%) | **样本外(后30%)** |
|---|---|---|
| **优化后** | 142 笔 · 胜率 65.5% · 均 +2.05% | **48 笔 · 胜率 56.2% · 均 +0.16%** |
| 默认参数 | 250 笔 · 胜率 51.2% · 均 +0.96% | 116 笔 · 胜率 30.2% · **均 −0.86%** |

**默认参数在样本外是亏钱的**，优化后转正。已应用的参数：

```json
chan: { min_stroke_bars: 3, power_ratio: 0.8 }
exit: { stop_pct: 0.10, take_pct: 0.08, max_hold: 25,
        use_chan_stop: false, exit_on_reverse: false }
```

系统给出的两个关键洞察：
- **关闭「缠论关键位止损」**：缠论给的止损位往往过近，正常波动就被扫出局，固定幅度止损更稳。
- **关闭「反向信号出场」**：买卖点转换频繁，会把持仓周期切得过短，错过趋势段。

> ⚠️ 用优化后参数做全样本回测显示总收益 +140%、胜率 63.2%，
> 但**这包含样本内数据，属于乐观偏差**。真实预期应以样本外为准
> （+0.16%/笔、胜率 56.2%）——仍为正，但远没有 140% 夸张。
> 参数会随市场环境漂移，建议每月用更大标的池重跑一次迭代。

## 二·六、量价关系（Volume-Price）

> 价格是方向，成交量是动力。缠论只看了价格的**形态**，
> 量价关系补上「这个形态有没有资金认可」这一维度。

### 核心思想

```
价涨量增 = 健康上涨（顺势持有）      价涨量缩 = 上涨乏力（警惕见顶）
价跌量增 = 恐慌抛售（危险）          价跌量缩 = 抛压衰竭（可能见底）
```

### 五类买入形态

| 代码 | 形态 | 识别逻辑 |
|---|---|---|
| `VP_B1` | 放量突破 | 放量 ≥1.8× 突破 20 日新高 + 均线多头 + 收阳 |
| `VP_B2` | 缩量回踩 | 上升趋势中量缩至 ≤0.7× 回踩 MA20，收在振幅上半部 |
| `VP_B3` | 地量止跌 | 量创 60 日地量 + 处于低位 + 收阳或长下影 |
| `VP_B4` | 底部放量反转 | 回撤 >12% 后放量大阳（>3%）或长下影放量 |
| `VP_B5` | 量价底背离 | 价格创出更低低点，但 OBV / MFI 反而更高 |

### 五类卖出形态

| 代码 | 形态 | 识别逻辑 |
|---|---|---|
| `VP_S1` | 放量滞涨 | 高位放量 ≥1.5× 却涨不动（收阴 / 长上影） |
| `VP_S2` | 量价顶背离 | 价格创出更高高点，但 OBV / MFI 反而更低 |
| `VP_S3` | 破位放量 | 放量跌破 MA20 或 20 日最低支撑 |
| `VP_S4` | 天量见顶 | 量创 60 日天量（≥3×）却无法收高 |
| `VP_S5` | 高位放量长阴 | 高位放量 ≥1.8× 且跌幅 >3% |

**背离检测用波段枢轴点（pivot）对比**，而非简单比较窗口极值——
后者在趋势股里几乎天天触发（实测顶背离信号会从 359 笔虚高降到 155 笔）。

每个信号都会给出**置信度、触发价、止损位、目标位（盈亏比 2:1）与文字理由**。
与缠论买卖点同向时标注「**缠论共振**」并 +12 分。

### 有效性验证（关键）

固定同一套出场规则（止损 10% / 止盈 8% / 最长 25 根K线），
只比较**入场信号**的差异，15 只标的 / 3 年：

| 信号源 | 样本内(前70%) | **样本外(后30%)** |
|---|---|---|
| 缠论买卖点 | 155 笔 · 胜率 60.6% · 均 +1.20% | 51 笔 · 胜率 51.0% · **均 −0.95%** |
| 量价关系 | 371 笔 · 胜率 64.7% · 均 +2.09% | 108 笔 · 胜率 50.0% · **均 −0.16%** |
| 缠论+量价共振 | 56 笔 · 胜率 76.8% · 均 +3.78% | 13 笔 · 胜率 69.2% · **均 +1.44%** |

换 8 只标的重跑，结论方向一致（缠论 −1.76% / 量价 −0.35% / 共振 +3.51%），
说明不是随机噪声。**三条诚实的结论**：

1. **量价信号样本外比缠论更抗跌**（−0.16% vs −0.95%），说明量能维度确实提供了增量信息；
2. **共振信号质量最高**，是唯一样本外仍为正的，但样本极少（约 1.8 笔/只/年），
   统计意义有限，适合当作「高置信度提醒」而非主要信号源；
3. **三个信号源样本内都赚、样本外都退化** —— 说明当前的**出场参数**是在样本内调优出来的，
   已经不适应近 9 个月的市场。这是下一步该解决的问题（不是继续加信号）。

> ⚠️ 因此量价提醒的使用建议：**当作缠论信号的确认/过滤，而不是独立开仓依据**。
> 缠论给出买点 + 量价同步看多 → 可信度最高；两者矛盾时降低仓位。

## 六、版本管理（Git）

仓库已用 Git 管理。**每次改完代码，跑一条命令即完成「提交 + 升版本 + 打标签 + 写日志」**：

```bash
python commit.py                                  # 自动汇总变更并提交
python commit.py "fix: 修复扫描报错" --patch       # 1.0.0 → 1.0.1，打 tag v1.0.1
python commit.py "feat: 新增港股通" --minor        # 1.0.0 → 1.1.0，打 tag v1.1.0
python commit.py "重构市场层" --major              # 1.0.0 → 2.0.0，打 tag v2.0.0
python commit.py --dry-run                        # 只看会提交什么，不真提交
python commit.py "..." --push                     # 提交后推送到远端（含标签）
```

`commit.py` 做的事：

1. `git add -A`
2. 按文件归类（核心引擎 / API / 前端 / 测试 / 文档 / 配置）生成结构化提交信息
3. `git commit`（统一 UTF-8，避免 Windows 控制台乱码）
4. 带 `--patch/--minor/--major` 时：更新 `VERSION`、在 `CHANGELOG.md` 顶部追加本次变更、打附注标签 `vX.Y.Z`
5. 带 `--push` 时推送分支与标签到 `origin`

版本号规则（SemVer）：`--patch` 修 bug / 文案；`--minor` 新增功能；`--major` 破坏性变更。

**不入库的内容**（见 `.gitignore`）：`data/cache/` 行情缓存、`data/*.db` 数据库（含自选股）、`logs/` 日志、
`__pycache__/`、以及下划线开头的临时脚本（`_probe.py` 之类）。换行符由 `.gitattributes` 统一为 LF
（`*.bat` 例外，必须 CRLF）。

常用查看命令：

```bash
git log --oneline --decorate -20    # 最近 20 次提交 + 标签
git tag                             # 所有版本标签
git show v1.0.0 --stat              # 某个版本改了什么
git diff v1.0.0..v1.1.0 --stat      # 两个版本之间的差异
```

## 七、注意

- 本系统用于**研究与辅助决策**，不构成投资建议。实盘前请自行验证信号。
- 行情为**延迟数据**（非实时 tick），不适合高频交易。
- 缠论买卖点具有主观性，不同参数设置会得出不同结论，建议结合其他维度交叉验证。
- 量价背离信号**天然滞后**：需等波段右肩走完才能确认，距枢轴点超过 12 根 K 线会扣分、
  超过 18 根则不再提示。止损位锚定在「形态证伪位」而非近期极值，避免止损过远。
- 量价提醒的止损空间按 ATR 推算，单笔风险超过 15% 会扣分、超过 27% 直接放弃该信号。
