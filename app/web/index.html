缠论的六个核心思想

缠论（缠中说禅《市场哲学的数学原理》）不是一套指标，而是一套 对走势进行完全分类的几何语言。它先把无序的价格波动标准化为 「分型—笔—线段—中枢」，再据此判断走势处在哪个阶段、何时可能转折。

期权策略分析

根据缠论买卖点自动匹配期权策略：一类/二类买点 → 现金担保卖出看跌（支撑位接货）或买入看涨； 三类买点/突破 → 买入看涨或牛市价差；卖点 → 持股则备兑看涨，空仓则买入看跌。 同时用 IV/HV 比值判断期权贵贱，决定买方或卖方倾向。

缠论参数

顶底分型之间至少间隔的合并K线数。默认 4（经典 5 根K线成笔）。调大 → 笔更少更稳定；调小 → 信号更灵敏。
后段 MACD 柱面积 / 前段面积 小于该值即判定背驰。默认 1.0。调小 → 背驰判定更严格。
